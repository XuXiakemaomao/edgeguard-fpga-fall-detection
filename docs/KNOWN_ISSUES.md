# 已知问题与限制

## Vivado `$readmemh` 相对路径

Vivado 2023.1 会相对于 HDL 文件所在目录解析 `$readmemh` 相对路径，而不是相对于
XPR、工程根目录或综合运行目录解析。移动源文件层级后必须同步调整权重路径。

把 `.mem` 加入 Design Sources 可能生成 `read_mem` 命令，但不能代替正确的相对路径。

## 板级数据口径

最终无串口源码完成时序、资源、功耗和比特流签核。板级逐帧指标来自带诊断接口的功能
构建，两类数据不能混写。

## 检测限制

- 板级测试样本少，存在两次误报。
- 慢速摔倒、遮挡、远景和复杂光照仍有挑战。
- 系统面向固定机位走廊，不适用于卧室。
- 输出为疑似告警，不是医学诊断。

## DRC

最终实现 DRC 为 0 errors、115 warnings。警告主要为工具级 DSP 流水建议、异步存储
控制检查及未约束 I/O，不阻止位流生成。
