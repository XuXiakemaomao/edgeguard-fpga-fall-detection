# FPGA 视频检测项目技能包

本技能包从“视频输入、运动检测、轻量 CNN、上板测试和交付整理”的实际开发过程提炼而来。
每个技能都写明适用范围、输入输出、执行步骤、验证方法和边界，便于迁移到其他 FPGA 视频项目。

## 技能列表

| 技能 | 解决的问题 | 适用广度 |
|---|---|---|
| `fpga-video-timing-bringup` | 视频流时序、缓存、复位、HDMI 调试、布线拥堵 | 广泛适用 |
| `edge-cnn-int8-deployment` | 轻量 CNN 训练、量化、RTL 对齐、上板评估 | 中等广泛 |
| `evidence-driven-fpga-validation` | 测试设计、误报复核、数据追溯、提交材料闭环 | 广泛适用 |

## 使用方式

1. 先根据问题选择技能，不要同时套用全部流程。
2. 每个技能先看“适用条件”和“输入”，条件不满足时不要直接使用结论。
3. 按检查清单执行，每一步保留原始数据、配置和验证结果。
4. 技能是开发方法，不替代具体板卡手册、接口协议和项目约束。

## 共同边界

- 技能来自固定机位、低分辨率处理和资源受限 FPGA 项目，不承诺覆盖所有视频场景。
- 设计修改必须经过仿真、综合、布局布线和上板验证。
- 任何性能数字都要注明来自仿真、时序报告、板级记录还是理论推算。
