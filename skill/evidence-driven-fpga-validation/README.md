# 工程证据闭环与可复现交付

## 技能类型

案例模板 + 踩坑清单 + 验证流程。

## 适用场景

需要同时提交源码、报告、测试视频、运行结果和可复现材料的 FPGA 项目。

## 使用方法

1. 按 `SKILL.md` 建立最终版本标签和证据分类；
2. 使用 `PROMPTS.md` 让模型检查报告、数据和代码是否一致；
3. 按 `CHECKLIST.md` 核对文件、哈希、指标来源和复现步骤；
4. 使用 `templates/test_matrix.csv` 记录测试，使用 `templates/manifest_template.md` 记录版本。

## 已验证效果

本项目使用该流程完成了测试矩阵整理、误报复核、关键文件哈希、最终提交代码分类和无串口代码清理。
最终报告能够区分实测数据、理论推算和待复测内容。

## 来源失败或观察

- 报告数字与最终比特流不是同一版本；
- 测试脚本混入最终代码包；
- 误报和失败案例被忽略；
- 串口删除后报告仍保留旧接口描述；
- 关键文件缺少清单和哈希。

## 失效条件

- 没有测试窗口、原始记录或版本信息；
- 只保留成功结果，无法核对失败案例；
- 最终代码和报告没有建立对应关系。
