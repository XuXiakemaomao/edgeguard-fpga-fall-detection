# 提示词模板

## 报告一致性检查

```text
请检查这份报告、最终源码、时序资源报告和测试数据是否一致。
重点核对：
1. 器件型号和时钟；
2. 最终比特流与报告数字是否来自同一构建；
3. 源码是否已删除报告中不存在的接口；
4. 每项任务指标是否有视频窗口和原始记录；
5. 哪些结论只能写成历史构建或待复测。
```

## 提交目录清理

```text
请依据官方提交要求检查目录。
只保留必要源码、约束、权重、构建脚本、验证结果、上板材料和说明；
列出多余文件、缺失文件和需要更正的文件名。
```

## 误报与失败复核

```text
下面是误报时间点、关键帧和原始记录。
请把事件分成真实误报、慢速摔倒候选、场景外动作和无法判断四类，
并说明重算指标时需要修改的 ground truth 和验证步骤。
```
