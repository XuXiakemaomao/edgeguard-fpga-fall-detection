# FPGA 视频流时序与上板调试

## 用途

用于固定机位视频流、HDMI 输入输出、行缓存、帧缓存、运动检测和显示叠加类 FPGA 工程。
重点是让视频链路按像素时钟稳定运行，并能从“没有画面、画面错位、时序不收敛、布线拥堵”等现象中定位问题。

## 适用条件

- 输入视频由像素时钟、DE、HS、VS 驱动；
- 设计包含行缓存、帧缓存、背景模型或显示叠加；
- 使用 Vivado 进行综合、实现和 post-route 时序分析；
- 输出链路可能包含 HDMI、DVI 或 TMDS。

## 输入

- 视频输入分辨率、刷新率和像素时钟；
- 顶层端口、板级约束和视频接收芯片配置；
- Vivado 综合、布局布线、时序、资源和 DRC 报告；
- 上板现象：无显示、花屏、错位、闪框、输入不识别等。

## 工作步骤

1. 先确认输入是否正常：时钟、DE、HS、VS、分辨率、配置总线。
2. 再确认输出是否正常：TMDS 时钟、数据对齐、显示时序。
3. 对无显示问题，先做独立输入测试，不要把视频接收配置和主处理链混在一起排查。
4. 对时序问题，只看布局布线后的时序报告，不接受综合前数字作为签核。
5. 对布线拥堵，检查缓存是否被拆成大量分布式存储、选择器，复位和使能是否存在超高扇出。
6. 修改后依次执行语法检查、模块仿真、完整顶层 elaboration、post-route 签核和上板验证。

## 常见问题与对应方向

| 现象 | 优先检查 |
|---|---|
| 无显示、电脑不识别输入 | 复位脉冲、配置总线、EDID、像素时钟、输入分辨率 |
| 画面横向错位 | 行缓存读写地址、DE/HS 对齐、显示流水线延迟 |
| 掩码或叠加层偏移 | 缓存 bank、读写端口、参考像素延迟 |
| 静止画面出现大框 | 背景模型、静止前景吸收、场景变化抑制 |
| 时序不收敛 | 地址乘法、BRAM 使能、并行计数器、复位扇出、packed bus |
| 布线拥堵 | 大数组是否被拆成分布式 RAM，是否存在动态多路选择 |

## 验证清单

- [ ] 输入分辨率和像素时钟正确；
- [ ] 所有时钟有明确约束；
- [ ] 复位释放顺序正确；
- [ ] 行缓存和帧缓存读写端口无冲突；
- [ ] post-route WNS/TNS、WHS/THS 和失败路径已记录；
- [ ] DRC 和布线状态无错误；
- [ ] 至少用静止、慢速、快速和全局变化视频完成上板测试；
- [ ] 最终比特流与报告、时序和资源数据来自同一次构建。

## 边界

本技能不替代具体板卡手册、视频接收芯片寄存器和接口电气规范。
它也不保证在任意分辨率、任意摄像头和任意光照下都能直接工作。
