# FPGA 视频流时序与上板调试

## 技能类型

踩坑清单 + 提示词工作流。

## 适用场景

固定机位视频流、HDMI 输入输出、行缓存、帧缓存、运动检测和显示叠加类 FPGA 工程。

## 使用方法

1. 读取 `SKILL.md` 的排查顺序和常见问题表；
2. 使用 `PROMPTS.md` 中的模板让大模型根据时序报告和模块结构提出排查建议；
3. 按 `CHECKLIST.md` 逐项确认输入、输出、缓存、时序和上板现象；
4. 修改后重新执行仿真、顶层编译、布局布线和上板验证。

## 已验证效果

本项目用于定位显示缓存分布式存储、区域计数复位扇出、背景行计数和 HDMI 无显示问题。
修改后完成了顶层语法检查、功能构建布局布线和显示链路恢复。具体时序数字以对应构建报告为准。

## 来源失败或观察

- 显示缓存被拆成大量分布式存储和选择器；
- 区域判决并行计数器导致复位扇出和长组合路径；
- 背景行计数重复加一，帧结束信号失效；
- 视频接收芯片复位脉冲丢失导致无显示；
- 缓存或显示流水线对齐错误导致画面偏移。

## 失效条件

- 没有具体板卡手册、管脚约束或视频接收芯片资料；
- 输入分辨率或像素时钟未知；
- 代码无法进入综合或时序报告不完整；
- 把综合前报告当成最终签核依据。
