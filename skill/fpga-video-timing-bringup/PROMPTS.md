# 提示词模板

## 时序与资源定位

```text
这是 Vivado post-route 时序、利用率和 DRC 报告，以及对应 RTL 顶层和关键模块。
请只根据报告和代码定位问题，不要先改代码。
请输出：
1. 最差路径经过哪些模块；
2. 哪些信号存在高扇出或长组合路径；
3. 哪些缓存可能被拆成分布式存储；
4. 最小修改方向；
5. 修改后需要重新检查哪些报告。
```

## 无显示排查

```text
FPGA 工程上板后无显示，电脑也不能正确识别输入。
现有信息：[视频接收芯片、分辨率、像素时钟、配置回读、复位方式]。
请把问题分成物理连接、视频配置、复位、像素时序和显示输出五层，
给出从便宜到复杂的排查顺序，并说明每一步的预期结果。
```

## 结果验证

```text
下面是修改前后的时序与资源报告。
请比较 WNS、TNS、WHS、THS、失败路径、LUT、FF、BRAM 和 DSP，
判断修改是否真的改善了问题；
如果没有改善，请指出可能是报告版本、约束或路径选择错误。
```
