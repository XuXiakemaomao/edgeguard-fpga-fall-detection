# 提示词模板

## Python 与 RTL 不一致

```text
下面是同一组输入的 Python 整数参考结果和 RTL 分层输出。
请逐层比较卷积、池化、全局平均池化、全连接和缩放结果。
不要只说“结果不对”，请指出第一处不一致的层、可能的舍入/饱和/索引原因，
以及下一次验证需要的 golden case。
```
