# 轻量 CNN 量化部署与评估

## 技能类型

提示词工作流 + 校验脚本 + 踩坑清单。

## 适用场景

资源受限 FPGA 上的小型图像分类网络，尤其是小尺寸灰度输入、类别数较少、只使用片上存储的模型。

## 使用方法

1. 按 `SKILL.md` 完成数据划分、训练、量化和 RTL 对齐；
2. 使用 `PROMPTS.md` 定位量化、存储和分类结果异常；
3. 使用 `scripts/cnn_int_reference.py` 对比整数参考；
4. 使用 `scripts/quant_compare.py` 比较浮点与整数指标；
5. 按 `CHECKLIST.md` 检查权重、golden case、综合日志和上板结果。

## 已验证效果

本项目在 1142 个测试样本上完成 8 位整数与浮点模型对比，准确率分别为 0.8196 和 0.8187，
输出一致率为 92.99%；整数参考和 RTL golden case 已完成逐层对齐。

## 来源失败或观察

- 权重版本不一致导致上板结果全为同一类；
- 输入量化表、缩放或舍入方式不同导致 Python 与 RTL 结果不一致；
- 前端 ROI 与训练裁剪分布不同，导致板级表现低于测试集；
- 推理完成信号和结果有效信号没有对齐。

## 失效条件

- 网络规模较大或需要外部 DDR；
- 输入尺寸、类别定义或量化规范未固定；
- 没有黄金参考或测试数据；
- 没有板级输出可比对。
