# 轻量 CNN 的量化部署与评估

## 用途

用于把小型图像分类网络部署到资源受限 FPGA，覆盖数据划分、训练、量化、权重导出、RTL 逐位对齐、上板推理和任务评估。

## 适用条件

- 输入图像较小，例如 48×48 灰度图；
- 类别数较少，例如正常、摔倒、其他；
- 网络以卷积、池化、全局平均池化和全连接为主；
- 目标器件没有外部 DDR 或只使用片上存储。

## 输入

- 按视频划分的训练、验证和测试数据；
- 浮点模型和权重；
- 量化规范：位宽、缩放、舍入和饱和策略；
- RTL 推理接口和输入裁剪范围。

## 工作步骤

1. 按视频划分数据，避免同一视频跨训练集和测试集。
2. 训练时使用量化感知前向，记录每层缩放参数。
3. 将权重、偏置、输入量化表、乘数和移位参数导出为存储文件。
4. 编写与 RTL 逐位一致的整数参考，逐层比较卷积、池化、全局平均池化和最终输出。
5. 在同一组 golden case 上验证 RTL 与参考完全一致。
6. 上板后检查输入裁剪、推理完成信号、分类结果和最终告警。
7. 比较浮点与整数模型的准确率、召回率、精确率和输出一致率。

## 常见问题

| 问题 | 可能原因 |
|---|---|
| 上板结果全为同一类 | 权重版本不一致、存储路径错误、量化缩放错误 |
| Python 与 RTL 分层结果不一致 | 舍入方式、饱和范围、卷积边界或池化索引不同 |
| 量化后召回明显下降 | 数据分布、每层缩放或输入量化表不合适 |
| 板级精度低于测试集 | 前端 ROI 与训练裁剪分布不一致 |
| 推理完成但结果无效 | 完成信号、结果有效信号或帧同步没有对齐 |

## 验证清单

- [ ] 训练、验证、测试按视频划分；
- [ ] 权重哈希与训练检查点一致；
- [ ] golden case 的每层输出和最终 logits 对齐；
- [ ] 综合日志确认权重读取成功；
- [ ] 上板输入裁剪与训练输入尺寸一致；
- [ ] 浮点、整数和板级指标分别记录，不混写。

## 边界

本技能适用于小型图像分类网络，不直接适用于大型目标检测网络、视频大模型或需要外部 DDR 的高吞吐模型。
