# Data policy

This repository does not redistribute raw third-party videos or the full derived
training tensor archive.

Included:

- training and evaluation scripts under `training/`;
- dataset split metadata;
- model checkpoints and INT8 deployment weights;
- golden cases;
- board-level result CSV files under `results/`;
- event windows and metric descriptions.

Users should obtain the original public datasets from their official sources and
follow the corresponding licenses.
